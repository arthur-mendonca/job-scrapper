## Why

The backend API is growing into the contract used by an operational frontend, but the frontend currently has no machine-readable source of truth for route shapes, DTOs, query parameters, request bodies, or response models. Adding OpenAPI generation from Fastify routes and Zod schemas lets the frontend use Orval to generate typed clients and hooks directly from backend-owned contracts.

## What Changes

- Add Fastify Swagger support to generate an OpenAPI document from registered routes.
- Add `fastify-type-provider-zod` so route schemas can be authored with Zod and converted into OpenAPI-compatible JSON schemas.
- Update API route registration to attach Zod-backed schemas for params, query strings, bodies, responses, and tags where practical.
- Add a backend CLI script that builds the Fastify app in memory, extracts the generated OpenAPI object, and writes it to a physical `openapi.json` artifact.
- Allow the frontend to consume the generated `openapi.json` from the backend repository, for example through a raw Git provider URL with an access token when the repository is private.
- Do not rely on a public `/docs` route or a running backend HTTP server for frontend code generation.
- Preserve existing private API authentication behavior for protected `/api` routes and keep `/health` outside protected route auth.

## Capabilities

### New Capabilities
- `api-openapi-contract`: Covers automatic OpenAPI generation for the Fastify API, static OpenAPI artifact generation, and Zod schema usage as the backend-owned API contract for frontend code generation.

### Modified Capabilities
- `system-architecture`: The API surface gains a documented, generated contract that operational consumers can use without moving business logic out of the backend.

## Impact

- Affected code: `package.json`, `pnpm-lock.yaml`, `src/server/server.ts`, `src/cli/generate-spec.ts`, route modules under `src/server/routes/`, and any shared API DTO/schema modules created for documentation.
- Affected APIs: Existing operational endpoints gain route schemas but should keep their runtime behavior and response shapes; `/docs` is not required as a public frontend integration point.
- Dependencies: Adds `@fastify/swagger`, `@fastify/swagger-ui`, and `fastify-type-provider-zod`.
- Systems: Enables frontend Orval generation from a committed or otherwise accessible `openapi.json` generated by the backend while preserving the private API deployment model.
